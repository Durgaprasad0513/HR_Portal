HR Management Portal
Field Requirements / Data Dictionary
Pattabhi Agro Foods Pvt. Ltd. — for developer handoff and database design

This document lists every field required to build each module of the HR Portal defined in the project scope, plus the supporting tables (user accounts, notifications, audit log) the scope implies but does not spell out field-by-field. Rows shaded red are restricted fields — visible only to HR Admin / Management Admin, never to the employee it belongs to or to other employees.
How to read this: This document assumes one table per module unless noted. In practice, each module maps to more than one database table (e.g. Travel Allowance needs a header table plus an expense-line table). Field lists are given at the level the developer needs to design tables — exact normalization is a build decision.

D. Gaps Found in the Original Scope
The scope document is thorough on modules and access levels, but it is incomplete as a field list. The following are missing and will surface as rework if not added now:
Gap in original scope: No SLA / due-date field anywhere in the Requests & Queries module — tickets can sit open indefinitely with no measurable target.
Gap in original scope: Payroll section lists "bank details" and "PF" as single line items — IFSC code and UAN number are both required in practice and are missing.
Gap in original scope: Asset table has no warranty/AMC expiry field, which is standard for IT asset registers and needed for replacement planning.
Gap in original scope: Audit trail example (Section 17) shows old value → new value, but doesn't specify a Record ID field — without it, an audit entry can't be traced back to the exact record that changed.
Gap in original scope: Admin activity logs and login history are called out in Section 17 as requirements but no fields are defined for either — both are listed above.
Gap in original scope: No password policy fields (minimum length, complexity, expiry interval) despite "password policy" being listed as a requirement in Section 17 — this needs to be a System Settings table, not just a stated rule.
Gap in original scope: Document expiry alerts are mentioned on the HR Dashboard (Section 15) but no document has an expiry field except where added above — extend this to any document type that can expire (contracts, certifications, work permits).
