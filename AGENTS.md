# Project Guidance

## Design System

Always read `DESIGN.md` before making visual or UI decisions. All typography, colors, spacing, component behavior, and aesthetic direction are defined there. Do not deviate without explicit approval. In QA mode, flag code that does not match `DESIGN.md`.

## UI Implementation

Prefer the existing React, Tailwind, and shared UI primitives. Adapt 21st.dev patterns selectively; do not replace the application with a downloaded template or introduce framework-specific Next.js code.
